## 1. 창업 아이템 개요

### 1.1 아이템명 및 브랜드 아이덴티티

**Uniwave (유니웨이브)**는 "University" (대학)와 "Wave" (변화의 물결)의 합성어로, 사회복지 현장실습의 **디지털 전환**을 선도하는 웹 기반 SaaS 플랫폼입니다.

**브랜드 철학**
- **Growth (성장)**: 대학 실습 과정을 통해 예비 사회복지사가 전문가로 성장하는 여정 지원
- **Connection (연결)**: 학생-실습기관-대학을 하나의 플랫폼에서 연결
- **Safety (안전망)**: 실습 관리의 체계성과 안정성 제공
- **Efficiency (효율성)**: 행정 업무 70% 절감을 통한 효율성 극대화

**슬로건**
- 영문: "Connected Practice, Trusted Growth"
- 국문: "실습을 연결하고, 성장을 신뢰하다"

### 1.2 사업 목적 및 핵심 가치

**사업 목적**
사회복지 현장실습의 전 과정(기관 매칭 → 일지 작성 → 피드백 → 평가 → 제출)을 디지털화하여 **학생·실습기관·대학의 행정 부담을 70% 감소**시키고, **실습 교육의 질을 30% 향상**시킵니다.

**핵심 가치 제안 (Value Proposition)**
1. **학생**: 웹/모바일 환경에서 실습일지 작성 → 작성 시간 **50% 단축** (20시간 → 10시간), 제본비 2.5만원 **절감**
2. **실습기관**: 슈퍼바이저의 일지 검토 업무 **70% 감소** (연 200시간 → 60시간), 승인 프로세스 자동화
3. **대학**: 실시간 진행률 모니터링, 조교 행정 업무 **70% 감소**, 한국사회복지사협회 인증 가능

### 1.3 주요 기능

#### MVP 핵심 기능 (2025년 1~3월 출시 예정)
1. **웹 기반 실습일지 작성**
   - PC/모바일 반응형 UI (앱 설치 불필요)
   - 사진 첨부, 실습 시간 자동 계산 (160시간 진행률 실시간 표시)
   - 오프라인 작성 지원 (PWA 기능)

2. **3자 실시간 소통 시스템**
   - 학생 ↔ 슈퍼바이저 ↔ 지도교수 간 피드백 및 질의응답
   - 카카오톡 알림 연동 (승인 완료, 미작성 리마인더)

3. **원클릭 PDF 자동 생성**
   - 학교 제출용 양식 (도장란, 결재란 포함) 자동 완성
   - 제본용 문서 다운로드 (하이브리드 제출 지원)

4. **관리자 대시보드**
   - 대학용: 실습생 진행률 통계, 미작성자 자동 알림, 우수 실습처 분석
   - 기관용: 학생 관리, 승인 일괄 처리, 평가 간소화

#### Phase 2 고도화 기능 (2025년 하반기)
- PWA 전환 (오프라인 지원, 홈 화면 추가)
- GPS 위치 인증 (출퇴근 자동 기록)
- 실습처 검색 (지역/분야 필터, 리뷰/평점 시스템)
- AI 일지 도우미 (GPT 기반 문장 추천, 우수 사례 제시) - 프리미엄 유료 기능

### 1.4 사업 모델

**B2B2C 하이브리드 구조**
- **B2B (주력)**: 대학 학과 단위 구독 (연 200~500만원/학과)
- **B2C (보조)**: 학점은행제·사이버대학 학생 개별 결제 (기본 무료 + 프리미엄 3만원)

### 1.5 목표 시장

**1차 타깃 (2025~2026)**
- 사이버대학 10개교 (한양사이버대, 서울디지털대 등)
- 학점은행제 평생교육원 상위 50개 기관 (연간 10,000명 실습생)

**2차 확장 (2027~)**
- 4년제 일반대학 사회복지학과 100개교
- 심리상담학과, 간호학과 등 타 전공 확장

**글로벌 진출 (2028~)**
- 베트남, 태국 등 동남아 사회복지 교육 시장

## 2. 문제 인식 및 해결 필요성

### 2.1 사회복지 현장실습의 구조적 문제

#### 2.1.1 현행 실습 제도의 3대 문제점

**법적 근거**
- **사회복지사업법 제11조**: 사회복지사 자격 취득을 위한 현장실습 **160시간 의무**
- **사회복지사 자격 관리 규정**: 실습확인서 제출 필수, 보건복지부 지정 기관에서만 인정

**문제 1: 행정 업무 과부하**
- **수기 서류 처리**: 실습확인서, 출석부, 평가서 등 연간 **수천 건의 종이 문서 처리**
- **엑셀 관리의 한계**: 100명 이상 학생 관리 시 데이터 누락, 버전 관리 어려움
- **3자 간 소통 단절**: 대학-학생-기관 간 전화/이메일 의존 → 실시간 정보 공유 불가

**문제 2: 학생 불편 및 경제적 부담**
- **160시간 실습 일지 수기 작성** → 손목 통증, 시간 낭비 (평균 20시간)
- **제본비 2만원 + 우편비 5천원** → 1인당 2.5만원 추가 부담
- **실습처 정보 불투명** → "뽑기 운", 부정 실습 리스크

**문제 3: 실습 품질 관리 어려움**
- **기관 선정 투명성 부족**: 보건복지부 선정 기관 **2,755개** (2025년 기준) 중 적합 기관 매칭 어려움
- **실습일지 피드백 지연**: 슈퍼바이저의 일지 확인까지 평균 **3-5일 소요**
- **역량 평가 기준 부재**: 실습 종료 후 정량적 성과 측정 어려움

#### 2.1.2 이해관계자별 고충

| 이해관계자 | 주요 고충 | 연간 손실 |
|----------|----------|----------|
| **학생 (25,458명)** | • 종이 일지 수기 작성 (160시간)<br>• 제본비 2만원 + 우편비 5천원<br>• 실습처 정보 불투명 ("뽑기 운") | 1인당 2.5만원 + 20시간 |
| **실습기관 (2,755개)** | • 학생 관리 서류 검토 (연 200시간)<br>• 전화 문의 대응 부담<br>• 평가 문서화의 복잡성 | 연 400만원 (인건비 환산) |
| **대학 (104개교)** | • 실습 진행률 실시간 파악 불가<br>• 조교 행정 업무 폭증<br>• 우수 실습처 확보 경쟁 | 학과당 연 500시간 |

#### 2.1.3 시장 규모 통계 (2024~2025년 기준)

**출처**: 보건복지부, 한국사회복지사협회, 교육부 대학 알리미

**실습생 규모**
- 일반대학 사회복지학과: 200여 개 × 평균 재학생 200명 = **40,000명**
- 사이버대학 사회복지학과: 21개 × 평균 700명 = **15,000명**
- 학점은행제 평생교육원: 추정 **20,000명**
- **연간 총 실습생: 약 75,000명**

**기관 현황**
- 보건복지부 지정 실습기관: **2,755개** (2025년 재선정 기준)
- 전국 사회복지관: **485개소** (한국사회복지관협회)
- 기타 사회복지시설: **2,270개** (노인·아동·장애인 시설 등)

**대학 현황**
- 일반대학 사회복지학과 개설: **200여 개**
- 사이버대학 사회복지학과: **21개교**
  - 한양사이버대학교: 재학생 약 6,000명
  - 서울사이버대학교: 재학생 약 5,000명
  - 경희사이버대학교: 재학생 약 3,000명

**시장 가치**
- **TAM (총 가능 시장)**: 연 **200억원** (실습생 25,000명 × 80만원)
- **SAM (실제 가능 시장)**: 연 **40억원** (침투율 20%)
- **SOM (초기 확보 목표)**: 연 **4억원** (점유율 10%, 3년차)

### 2.2 해결 필요성

#### 2.2.1 교육부·보건복지부 정책 방향

**디지털 뉴딜 정책 (교육부, 2024-2025)**
- 대학 LMS 고도화 및 비대면 실습 지원 강화
- 차세대 학습관리시스템 구축 예산 확대
- 2025년 교육부 예산: 대학 디지털 인프라 구축 **1,500억원**

**사회복지 현장실습 운영 개선 (보건복지부, 2025년)**
- 실습기관 재선정 제도 도입 (3년마다 갱신)
- 투명성·품질 관리 강화 지침
- 실습 확인서 전자 제출 허용 검토 중 (2026년 시행 예정)

#### 2.2.2 시장 수요 검증

**대학의 니즈**
- 코로나19 이후 **비대면 실습 관리 시스템** 도입 요구 급증
- 부산디지털대학교: 2024년 12월 "차세대 LMS 시범운영" 공지
- 한국폴리텍: "참인누리 차세대 스마트정보시스템" 구축 (2018년)

**학생의 니즈**
- Z세대 학생(사이버대·학점은행제)의 **모바일 기반 편의성** 요구
- 설문조사 결과: 학생 78%가 **웹 기반 실습 관리 시스템** 필요성 동의
- 학생 직접 결제 (49,900원) 의향: **78% 긍정**

**실습기관의 니즈**
- 행정 부담 경감 및 **실습생 역량 데이터** 확보 필요
- 슈퍼바이저 업무 시간: **주 5시간 → 2시간** 목표

#### 2.2.3 해결 시 기대 효과

**경제적 효과**
1. **행정 업무 70% 절감**: 종이 서류 제로화, 자동화된 프로세스 관리
   - 대학 교직원 1인당 연간 **1,000시간 → 300시간** (인건비 2,500만원 절감)
2. **종이 비용 절감**: 학생 1명당 연간 **A4 200장** (5,000원) → 100개 기관 × 100명 × 5,000원 = **연 5,000만원 절감**
3. **우편 비용 절감**: 실습확인서 우편 발송 **학생 1명당 3,000원** → 10,000명 × 3,000원 = **연 3,000만원 절감**

**교육적 효과**
1. **실습 품질 30% 향상**: AI 기반 피드백, 실시간 모니터링
2. **학생 만족도 향상**: 모바일 앱으로 편리한 실습 기록 및 소통
3. **기관 부담 경감**: 실습생 관리 자동화, 평가 보고서 자동 생성

**정책적 효과**
1. **보건복지부**: 실습 품질 관리 강화 → **사회복지사 전문성 향상**
2. **교육부**: 대학 LMS 고도화 사례 → **디지털 뉴딜 성과**

**강점**
- 10년 이상 시장 선점 경험
- 대학 네트워크 확보 (50개 대학)
- 안정적인 기술 기반

**한계**
- **타깃**: 일반대학 중심 (공학·경영 현장실습), 사회복지 특화 기능 부재
- **사회복지 특화 기능 부재**: 보건복지부 선정 기관 DB, 사회복지사 자격증 요건 미반영
- **가격**: 대학당 **연간 3,000만원 이상** (높은 진입장벽)
- **AI 기능 없음**: 수동 입력 중심, 자동화 부족
- **모바일 최적화 부족**: PC 중심 설계

#### 3.1.2 해외 경쟁사: Lumivero Experiential Learning Cloud (구 Tevera)

**특징**
- 미국 EdTech 기업으로 **$65.8M 투자 유치** (2024년 기준)
- **300개 이상 대학, 12만명 학생 관리**

## 4. 기술·서비스 내용 및 구현 방식

### 4.1 기술 아키텍처

#### 4.1.1 시스템 구성도

```
[사용자 (학생/기관/대학)]
↓
[프론트엔드: React + Tailwind CSS]
↓
[API 레이어: Node.js + Express]
↓
[인증 & 저장소]
- Supabase Auth (OAuth, MFA)
- PostgreSQL (실습 데이터)
- Cloudflare R2 (파일 저장소)
↓
[AI/ML (Phase 2)]
- OpenAI GPT-4o-mini API
↓
[PDF 생성: Python (ReportLab)]
↓
[배포 환경]
- Frontend: Vercel (프론트엔드)
- Backend: AWS EC2 (백엔드)
- CDN: Cloudflare (정적 파일)
```

#### 4.1.2 핵심 기술 스택

| 레이어 | 기술 | 선택 이유 |
|--------|------|----------|
| **프론트엔드** | React + TypeScript | 반응형 SPA, 컴포넌트 재사용성, 타입 안정성 |
| **UI 프레임워크** | Tailwind CSS | 빠른 개발 속도, 디자인 일관성 |
| **백엔드 API** | Node.js + Express | JavaScript 통합, 비동기 처리, 생태계 풍부 |
| **데이터베이스** | PostgreSQL | 관계형 DB, 복잡한 쿼리 지원, 안정성 |
| **인증** | Supabase Auth | OAuth, MFA 지원, Row Level Security |
| **PDF 생성** | Python (ReportLab) | 한글 지원, 복잡한 레이아웃 커스터마이징 |
| **AI 챗봇 (Phase 2)** | OpenAI GPT-4o-mini | 비용 효율적 (GPT-4 대비 1/10) |
| **파일 저장소** | Cloudflare R2 | S3 호환, 저렴한 egress 비용 |
| **배포** | Vercel (프론트) + AWS EC2 (백엔드) | 자동 배포, CDN 통합 |

### 4.2 주요 기능 구현 방식

#### 4.2.1 실습 신청 및 기관 매칭

**Flow**
1. 학생이 희망 지역·분야 입력 (예: 서울 노인복지관)
2. 시스템이 **보건복지부 선정 기관 2,755개** 중 매칭도 높은 순으로 추천
3. 기관별 **평균 평점, 리뷰, 담당자 정보, 실습 환경** 제공
4. 학생이 3지망까지 선택 → 대학 승인 → 기관 확정
5. 기관 슈퍼바이저에게 자동 알림 (카카오톡/이메일)

**기술**
- **검색 알고리즘**: PostgreSQL Full-Text Search + 거리 계산 (PostGIS)
- **추천 시스템**: Collaborative Filtering (향후 고도화: 학생 선호도 기반 AI 추천)

#### 4.2.2 웹 기반 실습일지 작성

**기능**
- PC/모바일 반응형 UI (Tailwind CSS)
- 사진 첨부 (실습 현장 사진, 최대 5장)
- 실습 시간 자동 계산 (출근 시간, 퇴근 시간 입력 → 160시간 진행률 실시간 표시)
- 오프라인 작성 지원 (PWA 기능: 네트워크 끊김 시 로컬 저장)

**기술**
- **Frontend**: React Hooks (useState, useEffect)
- **이미지 압축**: Browser-Image-Compression (파일 크기 최적화)
- **PWA**: Service Worker + IndexedDB (오프라인 캐싱)

#### 4.2.3 AI 챗봇 기반 실습일지 지원 (Phase 2)

**기능**
- **일지 자동 요약**: 학생이 작성한 일지를 3줄로 요약 → 슈퍼바이저 확인 시간 단축
- **질문 응답**: "오늘 클라이언트와의 대화에서 주의할 점은?" → GPT-4o-mini 실시간 답변
- **우수 사례 추천**: 유사한 상황의 다른 학생 일지 중 우수 사례 제시

**기술**
- **OpenAI API**: GPT-4o-mini (비용: 입력 $0.15/1M tokens, 출력 $0.6/1M tokens)
- **프롬프트 엔지니어링**: 사회복지 전문 용어 학습, 윤리 가이드 반영
- **비용 최적화**: 일지 1건당 평균 500 tokens → **건당 약 0.1원**

#### 4.2.4 3자 실시간 소통 시스템

**Flow**
1. 학생이 일지 작성 후 "승인 요청" 버튼 클릭
2. 슈퍼바이저에게 카카오톡/이메일 알림
3. 슈퍼바이저가 웹 대시보드에서 일지 확인 → 피드백 또는 승인
4. 학생이 피드백 받으면 즉시 알림
5. 지도교수는 전체 진행률을 대시보드에서 실시간 모니터링

**기술**
- **실시간 알림**: Firebase Cloud Messaging (FCM) 또는 카카오톡 알림톡 API
- **WebSocket**: Socket.io (실시간 채팅, 피드백)

#### 4.2.5 원클릭 PDF 자동 생성

**기능**
- 학교 제출용 양식 자동 완성 (도장란, 결재란 포함)
- 제본용 문서 다운로드 (A4 용지 기준, 페이지 번호 자동)
- 학생 정보, 기관 정보, 실습 시간, 일지 내용 자동 삽입

**기술**
- **PDF 생성**: Python (ReportLab) + 한글 폰트 (나눔고딕)
- **API 호출**: Node.js → Python 마이크로서비스 (AWS Lambda 또는 EC2)
- **템플릿**: 대학별 커스텀 양식 지원 (JSON 설정 파일)

#### 4.2.6 관리자 대시보드

**대학용 대시보드**
- 실습 진행률 (학생별, 기관별) → Chart.js 시각화
- 일지 제출률 통계 (일별, 주별, 월별)
- 평균 평가 점수 시각화 (레이더 차트)
- 문제 발생 알림 (장기 미제출자, 낮은 평가 등)

**기관용 대시보드**
- 실습생 관리 (이름, 연락처, 진행률)
- 승인 일괄 처리 (체크박스 선택 → 일괄 승인)
- 평가 간소화 (클릭 몇 번으로 평가서 완성)

**학생용 대시보드**
- 나의 실습 진행률 (160시간 중 현재 진행)
- AI 챗봇 피드백 히스토리 (Phase 2)
- 역량 평가 레이더 차트 (의사소통, 문제해결, 전문성 등)

**기술**
- **차트 라이브러리**: Chart.js (CDN)
- **실시간 업데이트**: Supabase Realtime Subscriptions

### 4.3 보안 및 컴플라이언스

#### 4.3.1 개인정보 보호

**최소 수집 원칙**
- GPS 위치 정보 수집 안 함 (Phase 2에서 선택적 기능으로 제공)

- 민감 정보 (주민등록번호, 연락처) AES-256 암호화
- 비밀번호: bcrypt 해싱 (salt 10 rounds)

**접근 제어**
- Supabase Row Level Security (RLS) 적용
- 역할 기반 접근 제어 (RBAC): 학생, 슈퍼바이저, 지도교수, 관리자

#### 4.3.2 법적 준수

**사회복지사업법 시행규칙** 준수

- 보건복지부 지정 기관만 인정

**개인정보보호법** 준수
- 개인정보 처리방침 명시
- 동의 절차: 회원가입 시 약관 동의
- 개인정보 파기: 실습 종료 후 5년 보관 (법적 의무) → 자동 삭제

**전자문서법** 대응
- 전자서명 법적 효력 확보 준비 (블록체인 기반)
- 하이브리드 제출: 디지털 + 아날로그 병행

#### 4.3.3 ISMS-P 인증 추진 (2026년)

**정보보호 관리체계 (ISMS)**

### 5.3 시장 진입 전략

#### 5.3.1 1차 타깃 공략: 사이버대학 + 학점은행제

**Why 사이버대학?**
- **디지털 친화적**: 온라인 수업 익숙 → 새 플랫폼 수용성 높음
- **학생 수 많음**: 한양사이버대 6,000명, 서울사이버대 5,000명 등
- **온라인 인프라 기 구축**: LMS 통합 가능성 높음

**Why 학점은행제?**
- **의사결정 빠름**: 일반대학 대비 **3개월 vs. 1년** (교수회의, 예산 승인 불필요)
- **비용 민감도 높음**: 민간 운영 → 저렴한 솔루션 선호
- **개인 학습자**: B2C 수익 확보 가능

**진입 방법**
1. **파일럿 프로그램 (2025년 3~4월)**
   - 사이버대 2개교 (한양사이버대, 서울디지털대) + 학점은행제 10개 기관
   - 학생 200명 (100명 × 2개교)
   - 3개월 무료 사용 → 성과 측정 → 유료 전환

2. **한국사회복지사협회 연계**
   - 협회 홈페이지 "현장실습센터"에 Uniwave 홍보
   - 협회 세미나/워크숍에서 데모 발표

3. **온라인 마케팅**
   - 네이버 블로그/카페: "사회복지 실습 후기" 키워드 타깃
   - 유튜브: 실습 준비 가이드 콘텐츠 제작

#### 5.3.2 2차 확장: 4년제 일반대학

**Why 후순위?**
- **의사결정 느림**: 교수회의, 예산 승인 절차 복잡 (6개월~1년)
- **기존 시스템 고착화**: WESS 등 이미 도입한 대학 있음
- **비용 부담**: 대규모 예산 필요 → 도입 장벽 높음

**진입 방법 (2026년~)**
1. **중소 지방대 타깃**
   - 예산 제약 있는 대학 우선 공략
   - **학생 직접 결제 모델** 강조 → 대학 부담 최소화

2. **레퍼런스 활용**
   - 사이버대 성공 사례 (행정 시간 70% 절감 실증)
   - 파일럿 기관 인터뷰 영상 제작

3. **보건복지부 협력**
   - 사회복지 현장실습 운영 개선 정책에 맞춰 제안
   - 정부 지원 사업 연계 (예: 디지털 뉴딜 예산)

#### 5.3.3 3차 확장: 타 전공 (심리상담학과, 간호학과 등)

**확장 전략 (2027년~)**
