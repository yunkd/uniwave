**창업 아이템명**: Uniwave (유니웨이브)  
**대표자**: 윤경대  
**작성일**: 2025년 12월 30일

## 1. 창업 아이템 개요

### 1.1 아이템명 및 핵심 가치
**Uniwave** (" University Wave" 의 합성어)는 사회복지 현장실습의 **디지털 전환**을 통해 **대학-학생-기관**을 하나의 플랫폼으로 연결하는 **사회복지 교육 SaaS** 입니다.

- **Uni**: 대학(University), 통합(Unified)
- **Wave**: 변화의 물결, 새로운 흐름

### 1.2 사업 목적
사회복지 현장실습의 **행정 비효율 제거**와 **실습 품질 향상**을 통해 예비 사회복지사의 전문성을 강화하고, 대학과 실습기관의 업무 부담을 경감합니다.

### 1.3 주요 기능
1. **통합 실습 관리**: 실습 신청, 기관 매칭, 일정 관리, 일지 작성/피드백 전과정 디지털화
2. **AI 챗봇 지원**: 실습일지 자동 요약, 실시간 질의응답, 우수 사례 추천
3. **QR 기반 출석 관리**: GPS 없이 안전한 출석 체크 (개인정보 보호)
4. **전자서명 시스템**: 실습확인서 온라인 처리 (보건복지부 인정 대응)
5. **데이터 분석 대시보드**: 실습 진행률, 학습 성과, 역량 평가 시각화

### 1.4 사업 모델
**B2B2C 구조**
- **B2B**: 대학이 플랫폼 구독 (서버비 + 운영비)
- **B2C**: 학생이 실습 시작 시 1회 결제 (49,900원)

### 1.5 목표 시장
1. **1차 타깃**: 학점은행제 평생교육원 상위 50개 기관 (연간 10,000명 이상 실습생)
2. **2차 확장**: 사이버대학교 21개교 + 일반대학 사회복지학과 200여 개

## 2. 문제 인식 및 해결 필요성

### 2.1 사회복지 현장실습의 구조적 문제

#### 2.1.1 행정 업무 과부하
- **수기 서류 처리**: 실습확인서, 출석부, 평가서 등 연간 **수천 건의 종이 문서 처리**
- **엑셀 관리의 한계**: 100명 이상 학생 관리 시 데이터 누락, 버전 관리 어려움
- **3자 간 소통 단절**: 대학-학생-기관 간 전화/이메일 의존 → 실시간 정보 공유 불가

**[통계 근거]**
- 전국 사회복지학과 개설 대학: **일반대학 200여 개 + 사이버대학 21개** (교육부, 2023)
- 사이버대학 사회복지학과 재학생: **연간 약 15,000명** (한양사이버대 6,000명 등 주요 3개 대학 기준)
- 학점은행제 평생교육원 실습생: **연간 약 20,000명 추정** (배움사이버평생교육원, KCU 등 상위 50개 기관)
- **연간 총 실습생 규모: 약 50,000명** (대학 15,000명 + 사이버대 15,000명 + 학점은행제 20,000명)

#### 2.1.2 실습 품질 관리 어려움
- **기관 선정 투명성 부족**: 보건복지부 선정 기관 **2,755개** (2025년 기준) 중 적합 기관 매칭 어려움
- **실습일지 피드백 지연**: 슈퍼바이저의 일지 확인까지 평균 **3-5일 소요**
- **역량 평가 기준 부재**: 실습 종료 후 정량적 성과 측정 어려움

**[법적 규정]**
- 사회복지사업법 시행규칙: 현장실습 **160시간 의무**, 실습확인서 제출 필수
- 전자서명 미인정 문제: 현재 **육필 서명만 인정** → 우편/방문 수거 필수

#### 2.1.3 학생 불편 및 안전 문제
- **출석 확인 방식**: GPS 기반 앱 사용 시 **개인정보 침해 우려**
- **기관 정보 부족**: 실습 전 기관 환경, 담당자 정보 등 사전 파악 어려움
- **응급 상황 대응**: 실습 중 안전사고 발생 시 신속한 보고 체계 미흡

### 2.2 해결 필요성

#### 2.2.1 교육부·보건복지부 정책 방향
- **디지털 뉴딜 정책**: 대학 LMS 고도화 및 비대면 실습 지원 강화 (교육부, 2024-2025)
- **사회복지 현장실습 운영 개선**: 투명성·품질 관리 강화 지침 (보건복지부, 2025년 재선정 공고)

#### 2.2.2 시장 수요 검증
- **대학의 니즈**: 코로나19 이후 **비대면 실습 관리 시스템** 도입 요구 급증
- **학생의 니즈**: Z세대 학생(사이버대·학점은행제)의 **모바일 기반 편의성** 요구
- **실습기관의 니즈**: 행정 부담 경감 및 **실습생 역량 데이터** 확보 필요

#### 2.2.3 해결 시 기대 효과
1. **행정 업무 50% 절감**: 종이 서류 제로화, 자동화된 프로세스 관리
2. **실습 품질 30% 향상**: AI 기반 피드백, 실시간 모니터링
3. **학생 만족도 향상**: 모바일 앱으로 편리한 실습 기록 및 소통
4. **기관 부담 경감**: 실습생 관리 자동화, 평가 보고서 자동 생성

**[문제 요약]**
- **문제 규모**: 연간 50,000명 실습생 × 160시간 = **800만 시간**의 실습 관리 필요
- **경제적 손실**: 대학 교직원 1인당 연간 **1,000시간** 실습 행정 업무 소요 → **인건비 약 5,000만원**
- **시급성**: 2026년 사회복지사 1급 응시자 예상 **2만명 이상** (자격증 취득 열기 지속)

## 3. 창업 아이템의 차별성 및 경쟁력

### 3.1 경쟁사 분석

#### 3.1.1 국내 경쟁사: 싸이웍스 WESS
**특징**
- 2013년 출시, **일반대학 현장실습 관리 시스템** 시장점유율 1위
- 50여 개 대학 도입 (한양대, 성균관대, 이화여대 등)
- 교육부 표준 업무매뉴얼 우수 사례 기재 (2017)

**한계**
- **타깃**: 일반대학 중심 (공학·경영 현장실습)
- **사회복지 특화 기능 부재**: 보건복지부 선정 기관 DB, 사회복지사 자격증 요건 미반영
- **가격**: 대학당 **연간 3,000만원 이상** (높은 진입장벽)
- **AI 기능 없음**: 수동 입력 중심, 자동화 부족

#### 3.1.2 해외 경쟁사: Lumivero Experiential Learning Cloud (구 Tevera)
**특징**
- 미국 간호·의료 실습 관리 시장 선도
- 실시간 학생 성과 추적, 인증 준비 기능 강화
- "5개의 분산된 시스템을 하나로 통합" 솔루션

**한계**
- **한국 시장 미진출**: 한국어 미지원, 한국 법규 (보건복지부 규정) 미대응
- **높은 가격**: 기관당 평생 구독 라이선스 **수만 달러**
- **범용 솔루션**: 사회복지 특화 기능 없음

#### 3.1.3 기타 경쟁사
- **Sonia, Typhon**: 미국 간호학 실습 관리 시스템 (한국 미진출)
- **대학 자체 LMS**: Moodle, Blackboard 등 범용 LMS (실습 관리 기능 부족)

## 4. 기술·서비스 내용 및 구현 방식

### 4.1 기술 아키텍처

#### 4.1.1 시스템 구성도
```
[프론트엔드]
Vue.js 3 + Tailwind CSS
↓
[API 레이어]
Hono Framework (TypeScript)
↓
[인증 & 저장소]
Supabase Auth + PostgreSQL
↓
[AI/ML]
OpenAI GPT-4o-mini API
↓
[배포 환경]
Cloudflare Pages (Edge Computing)
```

#### 4.1.2 핵심 기술 스택
| 레이어 | 기술 | 선택 이유 |
|--------|------|----------|
| **프론트엔드** | Vue 3 + TypeScript | 반응형 SPA, 모바일 최적화 |
| **백엔드 API** | Hono + Cloudflare Workers | 서버리스, 초고속 엣지 응답 |
| **데이터베이스** | Supabase (PostgreSQL) | Real-time DB, Row Level Security |
| **AI 챗봇** | OpenAI GPT-4o-mini | 비용 효율적 (GPT-4 대비 1/10) |
| **인증** | Supabase Auth | OAuth, MFA 지원 |
| **파일 저장소** | Cloudflare R2 | S3 호환, 저렴한 egress 비용 |

### 4.2 주요 기능 구현 방식

#### 4.2.1 실습 신청 및 기관 매칭
**Flow**
1. 학생이 희망 지역·분야 입력
2. AI가 **보건복지부 선정 기관 2,755개** 중 매칭도 높은 순으로 추천
3. 기관별 **평균 평점, 리뷰, 담당자 정보** 제공
4. 학생이 3지망까지 선택 → 대학 승인 → 기관 확정

**기술**
- **검색 알고리즘**: PostgreSQL Full-Text Search + 거리 계산 (PostGIS)
- **추천 시스템**: Collaborative Filtering (향후 고도화)

#### 4.2.2 AI 챗봇 기반 실습일지 지원
**기능**
- **일지 자동 요약**: 학생이 작성한 일지를 3줄로 요약 → 슈퍼바이저 확인 시간 단축
- **질문 응답**: "오늘 클라이언트와의 대화에서 주의할 점은?" → GPT-4o-mini 실시간 답변
- **우수 사례 추천**: 유사한 상황의 다른 학생 일지 중 우수 사례 제시

**기술**
- **OpenAI API**: GPT-4o-mini (비용: 입력 $0.15/1M tokens, 출력 $0.6/1M tokens)
- **프롬프트 엔지니어링**: 사회복지 전문 용어 학습, 윤리 가이드 반영
- **비용 최적화**: 일지 1건당 평균 500 tokens → **건당 약 0.1원**

#### 4.2.3 QR 기반 출석 관리
**Flow**
1. 기관이 **고유 QR 코드** 발급 (일주일마다 갱신)
2. 학생이 실습 시작 시 QR 스캔 → 서버에 출석 기록
3. GPS 사용 안 함 → **개인정보 보호** (위치 정보 수집 불필요)

**기술**
- **QR 생성**: QRCode.js (클라이언트 사이드)
- **출석 검증**: JWT 토큰 + 시간 제한 (30분 이내 유효)
- **보안**: QR 코드에 **기관 ID + Timestamp + HMAC 서명** 포함

#### 4.2.4 전자서명 시스템
**현황**
- 보건복지부: 현재 **육필 서명만 인정** (전자서명 미인정)
- Uniwave 대응: **PDF 전자서명 + 육필 서명 병행**

**Flow**
1. 실습 종료 후 학생이 온라인으로 확인서 작성
2. 슈퍼바이저가 **태블릿/PC에서 전자서명**
3. PDF 생성 → 학생이 **출력 후 육필 서명 추가** → 우편 발송
4. (향후) 보건복지부 전자서명 인정 시 **우편 단계 생략**

**기술**
- **전자서명**: PDF.js + Canvas 서명 입력
- **문서 관리**: Cloudflare R2 저장소 (암호화)

#### 4.2.5 데이터 분석 대시보드
**대학용 대시보드**
- 실습 진행률 (학생별, 기관별)
- 일지 제출률 통계
- 평균 평가 점수 시각화
- 문제 발생 알림 (장기 미제출자, 낮은 평가 등)

**학생용 대시보드**

**전체 사회복지 현장실습 시장**
- 일반대학 사회복지학과: 200여 개 × 평균 재학생 200명 = **40,000명**
- 사이버대학 사회복지학과: 21개 × 평균 700명 = **15,000명**

- 대학 서버비: 400개 기관 × 300만원 = **12억원**
- 학생 결제: 75,000명 × 49,900원 = **37억원**
- **TAM 총합: 약 50억원**

**시장 규모 (연간)**

- **SAM 총합: 약 10억원**

## 9. 결론

### 9.1 사업 요약

Uniwave는 사회복지 현장실습의 **디지털 전환**을 통해 **대학-학생-기관**을 하나의 플랫폼으로 연결하는 **사회복지 교육 SaaS**입니다.

- **문제**: 연간 50,000명 실습생 관리의 행정 비효율, 실습 품질 관리 어려움
- **솔루션**: AI 챗봇, QR 출석, 전자서명 기반 통합 플랫폼
- **시장**: 학점은행제 → 사이버대 → 일반대학 순차 확장
- **수익**: B2B2C 하이브리드 (대학 300만원/년 + 학생 49,900원/1회)
- **목표**: 3년 내 100개 기관, 20,000명 실습생, 매출 10억원

### 9.2 차별적 강점

1. **시장 선점**: 학점은행제 사회복지 실습 시장 **최초 진입**
2. **가격 경쟁력**: 기존 경쟁사 대비 **1/10 가격**
3. **기술 혁신**: AI 챗봇, QR 출석, 블록체인 전자서명
4. **검증 완료**: MVP 테스트 완료, 파일럿 기관 확보

### 9.3 기대 효과
